# M1 plan: scaffolding + benchmark

M1 builds a workspace that enforces the architecture rules, then a planted-trap benchmark with ground truth by construction, a scorer, two baselines, and first numbers in `EXPERIMENTS.md`. No engine code (ingest, ledger, agents, verifier, build) in M1.

## Decisions

- **Models:** Mistral Small 4 (`mistralai/mistral-small-2603` on OpenRouter) for every M1 model call, reached through a provider-neutral client, so the model and the provider are configuration. Baselines and, later, the engine are compared on the same model.
- **No LLM in the generator for M1.** Documents render from templates only: no generation cost, full determinism, and no path for a model to alter a planted value. Trade-off: documents read more templated; styling can be added later as an optional stage.
- **Thin `llmkit` slice in M1** (single call, replay cache, usage and cost), because baselines need a client and tests never call a live model. No tool loop.
- **One platform package.** The nine modules live in `haussmann`; workloads are separate packages. Layering between modules is an explicit import-linter contract, since `evalkit` must call `llmkit`.
- **PDF handling** uses pypdfium2 + pypdf in M1; the parsing ADR in M2 decides the long-term library with licensing in view.

## Layout

```
pyproject.toml                # the platform package + workspace root + all tool config
src/haussmann/<module>/       # coretypes llmkit docparse ctxkit ledger flow buildkit evalkit review
tests/<module>/
workloads/feasibility_fr/     # own package; benchmark/: fact schema, templates, scenarios, baselines
docker/postgres/Dockerfile  compose.yaml  .github/workflows/ci.yml
docs/{plan,notes,adr}/  EXPERIMENTS.md
```

Trap pass conditions (detail in the ground-truth note):

| Trap | Passes when |
|---|---|
| CONTRADICTION | higher-authority value reported, fact flagged, both sources cited (equal-authority ties come later) |
| SUPERSEDED | latest value reported, amendment cited |
| BURIED | value reported with a citation to the right page |
| UNIT | normalized value correct |
| ARITHMETIC | total recomputed and the discrepancy flagged |
| DATE_LOGIC | fact flagged |
| MISSING | abstention with an open question |
| DISTRACTOR | none of its values used |

## Out of M1

The `llmkit` tool loop, the `ctxkit` assembler, the verifier and `buildkit` are not started. The scorer's value matching is kept separate from the future verifier's citation check, so the grader and the system under test cannot share a bug. The prose rubric judge arrives with the writer in M2.

## Exit criteria

All gates green; both baselines scored on both dev scenarios, 3 samples each; rows in `EXPERIMENTS.md` including run-to-run spread; if baseline (a) passes more than about 85% of traps, the scenarios are hardened before M2.
