# ADR-0003: Rendering stack for benchmark documents

Status: accepted, 2026-11-10

The benchmark generator renders PDFs with ReportLab (BSD), spreadsheets with openpyxl (MIT) and emails with the standard library. Scanned PDFs are made by rasterizing pages with pypdfium2 (BSD-3-Clause or Apache-2.0) and degrading and reassembling them with Pillow (MIT-CMU). pypdf (BSD-3-Clause) reads text back in tests to check that every statement is where the manifest says. These four rendering libraries are declared as an optional extra, `haussmann[generate]`, because they are needed to regenerate scenarios and not to run the engine or the scorer; pypdf is a development dependency until a runtime module needs it, as are the type stubs for ReportLab and openpyxl. pypdfium2 ships no type information, so the one file that uses it relaxes the type checker for that import. All are pure-Python or ship wheels, so CI installs nothing from the system. Alternatives considered: WeasyPrint or a headless browser (system libraries or a browser binary, and no direct page mapping for blocks); LaTeX or Typst (an external binary); PyMuPDF for rasterizing and reading (AGPL, which would constrain how this repository can be used); a document-augmentation library for scan effects (a large dependency for a handful of image operations). Licences were read from PyPI on 2026-11-10.
