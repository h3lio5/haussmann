# ADR-0010: Review screen stack

Status: accepted, 2026-11-14

The review screen is a single-page application in `web/`, written in TypeScript with React, built with Vite, and it draws PDF pages with PDF.js (`pdfjs-dist`); these are the four the project's stack names, and nothing else is added: no router, no state library, no component kit, no CSS framework. React and TypeScript give typed components over the API's JSON, whose shapes are written once in `web/src/api.ts`; Vite gives a development server with a proxy to the API and a static build that the API process serves, so the demo is one command; PDF.js is what makes "click a sentence, see its source" land on the page as it was scanned or printed, with the quote marked on it, and not only on extracted text. All four are permissively licensed (MIT, MIT, MIT, Apache-2.0). Cost: a second toolchain in the repository (Node, a lockfile, a build step) and a bundle of about half a megabyte, most of it the PDF renderer; the screen is checked by the TypeScript compiler and by hand in a browser, and has no automated interaction test yet. Alternatives considered: server-rendered pages with no build step (the evidence pane changes on every click and the PDF canvas needs client code anyway); a component library (the screen is two panes and a dozen controls, and a kit would decide how it looks); showing only extracted text (cheaper, and it would hide exactly the cases a reviewer distrusts: scans and tables).
